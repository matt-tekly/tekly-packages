What to build next

Every gap the three screens hit, counted by how many screens need it.

GapScreensWhere it shows upToday's workaround
Punch3Score lands, every coin hitting the HUD, the chosen card settling, the chest before it opens.A Scale clip with Elastic Out. It cannot stack on top of a running Scale clip, which Punch needs since it is layered.
Stagger children3Stars, buttons, reward chips, cards, items, coins.One Tweenline per child with Stagger set. Six coins mean six components with the same animation copied.
Count up2Score 0 to 48,250, coin HUD 1,240 to 1,740.Code on a marker. Not scrubbable or hurried with the rest.
Shake2Screen shake on the title slam, chest rattling before it opens.Hand keyed Rotation and Position clips. Tedious and not seeded.
Reverse from current time1Card hover lift. PlayReverse starts at the end, so leaving mid lift snaps up before dropping.A second Hover Out animation with From set to Current.
Move to a target1Coins flying to the coin counter, whose position depends on the HUD layout.A Position clip with a hand typed offset that breaks when the layout changes. Already on the 3D list as "move towards a target Transform".
Arc or path motion1Items leaping out of the chest, coins arcing to the HUD.Works now: a Position clip plus a one hop Bounce clip gives a clean arc. Worth documenting as a recipe instead of a new track.
Chain into Idle2Rays spinning after Show, Claim and Take button shine loops.A second Tweenline on the looping object, started by a marker. Works but needs a component per loop.
Image fill1XP bar filling from 40% to 85%.Scale X on a masked child. Fine for bars, wrong for radial fills.
Typewriter1Card screen subtitle.None without TMP access.
Graphic color1Claim button tinted grey until the count finishes.Swap sprites with Active steps. Note that a white flash cannot be done with Graphic color because UI tint multiplies, so the star flash here uses a white overlay with an Alpha track.

Not Tweenline's job and handled with markers: confetti and sparkle particles, sound, spawning pooled coins, and pointer input that plays Hover and Select.
